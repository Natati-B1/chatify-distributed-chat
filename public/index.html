Chatify is a real-time chat application built with a distributed backend for high availability, scalability, and reliability.

Get Started Learn More

Features

Real-time messaging with WebSockets, multiple chat server nodes behind Nginx, Redis Pub/Sub for cross-node delivery, and MongoDB for durable history—with eventual consistency for scale and availability.

About

Chatify demonstrates a distributed pattern: clients hit a load balancer, application nodes share state through Redis, and messages persist in MongoDB so the UI stays fast and reliable.
